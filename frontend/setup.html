Eerste installatie van Paramant

Het instellen van je server duurt ongeveer 5 minuten. Deze wizard werkt maar één keer. Zodra je eerste gebruiker is aangemaakt, gaat hij dicht.

Stap 1 van 6: kies je sectoren

Elke sector krijgt een eigen server, met de regels die voor die sector gelden.





Stap 2 van 6: domein en TLS

Op welk domein bereiken gebruikers deze server?

Laat dit leeg als de server alleen lokaal draait, op localhost. Dan is er geen publiek domein en geen TLS.

Daarvoor heeft elke sector een eigen subdomein nodig, met een DNS A-record.

Stap 3 van 6: e-mail van de beheerder en beveiliging

Stap 4 van 6: eerste gebruikersaccount

Maak de API-sleutel voor je eerste gebruiker. Je ontvangt hem per e-mail.

Stap 5 van 6: compliancesjabloon

We stellen de bewaartermijnen, het auditlog en de levensduur van bestanden (TTL) alvast in voor je situatie.

Stap 6 van 6: controleren en starten

Controleer je instellingen voordat je ze toepast.

Bij het starten schrijft de server deze eenmalige code in het bestand setup-token, naast users.json. De code komt niet in het logboek. Zo kan alleen wie de server beheert de installatie afronden.

Je server draait

De installatie is klaar. Log in op het dashboard om je eerste bestand te versturen.
