Verify

Check a Paramant proof

Two kinds of proof come out of Paramant: a signed document, and a receipt that says a file was delivered and then destroyed. Both are checked here, on your own device. Nothing you drop in is uploaded, and neither check needs an account.

1

Original document

2

.psign envelope

This is a legacy (v1/v2) envelope; its relay notary signature can only be checked by the relay, which requires an API key. Current signatures verify fully offline with no key.

3

Verify

What is checked

  • SHA3-256 of your document matches the hash inside the envelope
  • The signer's ML-DSA-65 signature over that hash is valid
  • The envelope has not expired

Signatures verify entirely in your browser — no account, no API key, works offline.

1

The receipt

A delivery receipt is the small block of text you get when a file you sent is picked up. It says which file was handed over, at what moment, and whether the copy on the server was destroyed.

2

Check it

Checking a receipt from another server

This page carries the signing key of every Paramant relay, and picks the one the receipt names, so the usual receipt is checked without asking anything of the network. A receipt from a server you run yourself is checked by pasting that server's key below.

Every relay publishes its own key at /v2/pubkey, for example .

What is checked

  • The receipt is about the file it names and no other
  • The entry it points to really sits in the public transparency log
  • The signature over the whole receipt holds, so nothing was altered
  • The log snapshot the receipt leans on was signed too

All four run on this device. Once the page has loaded you can pull the plug and the answer is the same.
