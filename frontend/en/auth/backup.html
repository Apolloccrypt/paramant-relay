backup recovery

Use a backup code.

Use one of the codes you saved when you set up your account; each code works once and gets you in without your authenticator app.

Twelve characters, three groups of four, separated by dashes. Capitals do not matter.

Do this once you are in

A used code is gone. Open your account settings to issue a fresh set of backup codes, and to link a new authenticator app if the old one is lost for good.
