Code inwisselen

Een code geeft u een periode cadeau. Het is geen korting en geen betaling: er wordt niets afgeschreven, nu niet en later niet, en er valt niets op te zeggen.

Een code hoort bij een account, dus u hebt eerst een account nodig. Een Community-account is gratis en vraagt alleen een e-mailadres. Uw code wordt bewaard en weer ingevuld als u hier terugkomt.

Wat een code is

Een code is een cadeau, geen aankoop. Er is geen kaart gevraagd, er is niet betaald en er zit geen abonnement achter. Er valt dus niets op te zeggen en er wordt niets afgeschreven als de periode afloopt.

Op de laatste dag gaan de producten terug naar het gratis Community-abonnement en blijven daar gewoon werken. Een week van tevoren krijgt u een e-mail.

Een periode die u al betaald heeft, wordt niet vervangen. Het cadeau komt erbovenop, dus u verliest geen dag die u kocht.
