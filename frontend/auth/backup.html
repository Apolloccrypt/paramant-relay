back-upcode

Gebruik een back-upcode.

Gebruik een van de codes die u bewaarde toen u uw account instelde. Elke code werkt één keer en laat u binnen zonder uw authenticator-app.

Twaalf tekens, drie groepen van vier, gescheiden door streepjes. Hoofdletters maken niet uit.

Doe dit zodra u binnen bent

Een gebruikte code is op. Open uw accountinstellingen voor een nieuwe set back-upcodes, en om een nieuwe authenticator-app te koppelen als de oude echt weg is.
