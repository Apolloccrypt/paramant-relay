How payment works

Payment runs through Mollie. Every payment is a one-off for the term you buy: one month, or one year paid up front. Automatic renewal is not switched on, so there is no direct debit mandate and no subscription that renews by itself. ParaSign and ParaSend each carry their own paid term. When a term ends, that product falls back to its free Community plan, and nothing is charged again unless you buy the next term yourself.

ParaSend · Send a file that disappears

Send a file over a link that expires and wipes the file after the last read it allows. The web app and the extensions delete the file after the first read on every plan. Through the API a paid link can allow more reads: up to 10 reads on Pro, 25 on Business and 100 on Enterprise. Community covers 10 transfers a month at 5 MB per file, forever. Organisations that send every week pay for longer links, more reads through the API and more registered devices. More reads is not a weaker promise: it is one link a whole team can open, or a counterparty reopening it after a misclick, instead of you sending the file a second time.

In the web app you and the receiver are both online and compare a short code, and the file is handed over live. Sending to someone who is not online right now needs the API, the SDK, or the Send a link mode in the web app.

Limits

Every tier stores transfers in RAM. What differs by tier is how long the link lives, how many times it can be read, and how many devices can register for verified transfers. Enterprise customers running a dedicated relay can configure limits within the RAM budget of their deployment.

Encryption

Every tier uses the same cryptography. Verified transfers from the ParaSend web app use ML-KEM-768 plus ECDH P-256 hybrid key exchange; the crypto register lists the web app with no default signature algorithm, on a pre-v1 hybrid wire format that is migrating to v1. There is no lesser encryption at lower tiers. Cryptography is not a paywalled feature at Paramant.

Compliance

The architecture is built to support your NIS2 and GDPR work. Paramant itself holds no third-party certification for those frameworks. Two mappings are written and published with the source, and neither sits behind a plan: an IEC 62443 requirement table in the OT guide, and a NEN 7510 table in the DICOM guide. A Community account can read both. There is no eIDAS mapping document. The standard Data Processing Agreement under GDPR Article 28 is published at /dpa and applies to all plans; it can be signed electronically, with no account and no paid tier required.

Support

The Community plan is self-service via public documentation and the CT log. Pro tier includes email support with published response targets. Enterprise customers get a named contact, a 99.95% SLA, priority incident handling, and deployment assistance for air-gapped and regulated environments.

Frequently asked questions

What happens to my file after the recipient downloads it?

All files are RAM-only. They exist only in server memory and are wiped after the last read the link allows. The web app and the extensions delete the file after the first read on every plan. Through the API a paid link can allow more reads: up to 10 reads on Pro, 25 on Business and 100 on Enterprise. TTL expiry wipes them too. Nothing persists after expiry on any tier. There is no disk storage.

Can I self-host Paramant for free?

Yes. The relay is available on GitHub under BUSL-1.1. Community self-hosting is free forever. The license prevents competitors from reselling the relay as a managed service without a commercial license. See the license page for full terms.

Is there a free trial for Pro?

There is no separate trial: every product has a Community tier forever, so you can try the core flow at no cost and upgrade to Pro or Business when you need higher limits. Create a free account to start, no card required; the Pro and Business buttons above take you straight to checkout.

How does ParaSign pricing work?

ParaSign is priced by signature volume, not by feature. Community covers 2 signatures a month; Pro (€49/mo or €499/yr, excl. btw) includes 100 a month, then €0.40 each, with API access; Business (€299/mo or €2,990/yr, excl. btw) includes 1,000 a month with named support and an exportable audit log. Every tier uses the same ML-DSA-65 post-quantum cryptography and public CT-log verification. A ParaSign signature is a Simple Electronic Signature (SES) under eIDAS, not an advanced (AES) or a qualified (QES) signature. QES is coming via an EU QTSP partner.

Is a Simple Electronic Signature enough for my documents?

Under Dutch law an ordinary electronic signature has the same legal effect as a handwritten one, provided the method used for signing is sufficiently reliable in the light of the purpose for which it was used and all the other circumstances of the case (Dutch Civil Code, art. 3:15a, wetten.overheid.nl BWBR0005291). A qualified signature (QES) shifts the burden of proof: with a QES that reliability does not have to be shown. With a simple signature it is an open standard, and ParaSign is built to make the reliability demonstrable: every signature produces a receipt and an entry in a public log that anyone can check. This is not legal advice; ask your own counsel what your matter needs.

Do all plans include a GDPR Data Processing Agreement?

The standard DPA is publicly available at /dpa and applies to all plans. Enterprise customers can negotiate custom DPA terms as part of their contract.

What does "IEC 62443 / NEN 7510 / NIS2 compliance documentation" mean?

Architecture documents, security controls mappings, and technical reference materials aligned to these frameworks. This is documentation you can use as input for your own compliance process. Paramant does not hold third-party certification for these frameworks.

What happens if Paramant shuts down?

Paramant is published under BUSL-1.1. If the managed service ever closes, every self-hosted relay keeps running indefinitely. The source code is permanently available on GitHub. No vendor lock-in by design.
