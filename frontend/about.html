01 / Wat het is

Wat Paramant is

Twee dingen: versturen en ondertekenen. Versturen versleutelt een bestand in uw browser voordat het uw apparaat verlaat; de server houdt alleen het verzegelde bestand vast, in het geheugen, en wist het na de laatste keer lezen. Ondertekenen zet een handtekening die iedereen later kan controleren, en zet elke handtekening in een openbaar logboek.

De uitgangspunten blijven gelijk: privacy eerst, bestand tegen toekomstige quantumcomputers, en servers in Europa zonder Amerikaans moederbedrijf. Het doel is niet om uw vertrouwen te vragen, maar om het overbodig te maken.

De techniek, voor wie het wil weten

Versturen heet in de code ParaSend, ondertekenen ParaSign. Handtekeningen gebruiken ML-DSA-65 (FIPS 204), in uw browser gemaakt; de private sleutel komt nooit op de server. Versturen uit de webapp is hybride: ML-KEM-768 samen met ECDH P-256. De code is source-available en staat op GitHub.

03 / Nakijken

Hoe u ons kunt nakijken

Elke bewering op deze site is bedoeld om na te kijken, niet om op te vertrouwen. Vier dingen maken dat mogelijk:

Handtekeningen op uw apparaat

De sleutel wordt in uw browser gemaakt en komt nooit op onze server.

Een openbaar logboek

Elke handtekening komt in een openbaar logboek waar alleen iets bij kan. Bekijk het in het logboek.

Offline te controleren

Een getekend document is te controleren zonder contact met ons. Probeer het op de controlepagina.

Code die u kunt lezen

De server is source-available. Lees hem op GitHub en draai hem zelf.

Een gewone elektronische handtekening, geen gekwalificeerde. Een handtekening met Paramant is in eIDAS-termen een Simple Electronic Signature (SES). Het is geen gekwalificeerde elektronische handtekening (QES). We zeggen precies wat het wel en niet is.
